# 🎓 Student Grade Tracker

A **GUI-based Student Grade Tracker** built using **Java Swing** as part of the **CodeAlpha Java Programming Internship – Task 1**.

## ✨ Features

* ➕ Add student
* 🔍 Search student by name
* ✏️ Update student grade
* 🗑️ Delete student
* 📋 View all student records
* 📊 Calculate average, highest & lowest scores
* 🎯 Automatic A–F grade calculation
* ✅ Input validation
* 🖥️ Clean and user-friendly GUI

## 🛠️ Technologies

- Java
- Object-Oriented Programming
- ArrayList
- Scanner
